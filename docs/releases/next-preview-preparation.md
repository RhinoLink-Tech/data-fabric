## User-facing changes to verify

- **Source discovery and management:** bounded MCP source lists and schema search continuations; testing an edited source with its retained credentials. Default-off MariaDB and openGauss browser onboarding candidates require verified TLS, network restrictions and the respective driver. They are not yet independently accepted in WorkBuddy or a published image ([#761](https://github.com/RhinoLink-Tech/data-fabric/issues/761), [#781](https://github.com/RhinoLink-Tech/data-fabric/issues/781)).
- **Queries and SQL conversion:** the repository Skill supports standalone translation without running a query. Initial MCP query pages default to 100, with explicit sizes up to 10,000; continuation keeps the effective size. Opt-in no-count is limited to MySQL, PostgreSQL and Trino, returns an unknown total rather than zero, and retains exact count by default. Complex Trino pagination windows can be rejected. Federated verification used synthetic MySQL/PostgreSQL data through Trino 484, not all sources or clients ([#450](https://github.com/RhinoLink-Tech/data-fabric/issues/450)).
- **Local deployment:** Core and SQLite metadata are optional experimental candidates, not published profiles. The SQLite Compose candidate is loopback-only and does not establish public WorkBuddy OAuth, production readiness or an upgrade contract ([#444](https://github.com/RhinoLink-Tech/data-fabric/issues/444), [#448](https://github.com/RhinoLink-Tech/data-fabric/issues/448)).

Repository Skill changes do not automatically update an existing WorkBuddy marketplace listing. Actual WorkBuddy OAuth, source lifecycle, independently operated first use and external-team value remain separate acceptance items ([#504](https://github.com/RhinoLink-Tech/data-fabric/issues/504), [#541](https://github.com/RhinoLink-Tech/data-fabric/issues/541), [#603](https://github.com/RhinoLink-Tech/data-fabric/issues/603), [#446](https://github.com/RhinoLink-Tech/data-fabric/issues/446), [#458](https://github.com/RhinoLink-Tech/data-fabric/issues/458)).
