## 已评估的用户路径

已评估的自部署路径使用 MySQL 8.4 元数据和合成 MySQL 样例数据。只有运营者提供可信 HTTPS 地址，以及明确配置外部 OIDC 签发方、audience 和 scope 后，才能使用授权 REST 管理与远程 MCP。该包提供只读数据源发现与查询、有边界的分页，以及不执行 SQL 的方言转换能力。

请按照安装指南下载并校验源码包，并使用其中给出的精确镜像引用；不要把固定摘要替换成浮动标签。

## 保留的边界

本发布没有证明公开 WorkBuddy 服务、账号自助开通、通用客户端自动 OAuth、实际市场生命周期、外部采用或真实客户数据结果。MariaDB、openGauss 与 TiDB 的浏览器接入仍是默认关闭的候选功能，受各自数据源条件约束；评估这些路径前请阅读历史候选记录。
