# 安装 v2.1.0-preview.3 镜像

[English](v2.1.0-preview.3-install.md) · [正式发布记录](v2.1.0-preview.3-zh.md) · [候选范围与风险](v2.1.0-preview.3-candidate-zh.md) · [发布下载与不可变镜像摘要](https://github.com/RhinoLink-Tech/data-fabric/releases/tag/v2.1.0-preview.3)

本指南仅在 `v2.1.0-preview.3` 已有公开 GitHub Release 和不可变镜像摘要后适用。它启动一个自部署的 `linux/amd64` 评估配置：MySQL 8.4 元数据与合成样例数据。它不构成生产可用性、高可用、性能 SLA、自动故障切换或任意客户端 OAuth 的承诺。

需要 Docker Engine 24+、Docker Compose 2.24+、Python 3、OpenSSL、`curl`、`tar` 与 `sha256sum`。发布镜像本身不需要本机安装 Go 编译器或 Python 包。远程 MCP 还需要受信任的 HTTPS 地址、OIDC 签发方、正确配置的 audience，以及带文档规定查询 scope 的令牌。请使用新的 Compose 项目，并只接入合成或已明确批准的数据。

## 1. 下载并校验发布文件

在一个新的空目录中执行。先核对发布页列出的源码包校验和：

```bash
VERSION=v2.1.0-preview.3
ARCHIVE="data-fabric-${VERSION}-source.tar.gz"
BASE="https://github.com/RhinoLink-Tech/data-fabric/releases/download/${VERSION}"
curl -fL -o "$ARCHIVE" "$BASE/$ARCHIVE"
curl -fL -o "$ARCHIVE.sha256" "$BASE/$ARCHIVE.sha256"
sha256sum -c "$ARCHIVE.sha256"
tar -xzf "$ARCHIVE"
cd "data-fabric-${VERSION}/deploy/mcp"
```

校验失败必须停止。此校验针对下载的源码包，不针对容器镜像；不要换用未发布镜像或其他版本的摘要。

## 2. 初始化并配置

选择一个未被其他安装使用的 Compose 项目名，并在后续命令中保持一致：

```bash
export COMPOSE_PROJECT_NAME=data-fabric-preview3
python3 ../../scripts/mcp/onboard.py init --directory "$PWD"
```

将 `.env` 权限保持为 `0600`。根据自己的身份服务设置 `MCP_OIDC_ISSUER` 和 `MCP_OIDC_AUDIENCE`，并配置所需 scope。把对应 GitHub Release 中的**完整标签和摘要引用**写入 `.env` 中唯一未注释的 `DATA_FABRIC_IMAGE`：

```text
ghcr.io/rhinolink-tech/data-fabric:v2.1.0-preview.3@sha256:0c5ada5c16f9a411ecc80f8fd1635733ab7e88cb5f2bdc2d74f27b54ca6278af
```

上面是本 Preview 已发布镜像的精确不可变引用。自动生成的证书只适合本机评估，远程使用前请改用受信任证书。妥善保护 `.env`、TLS 私钥与凭据密钥环；丢失或替换密钥环可能导致已保存的数据源凭据无法读取。

## 3. 启动并诊断配置

```bash
docker compose -f docker-compose.yml -f docker-compose.release.yml pull
docker compose -f docker-compose.yml -f docker-compose.release.yml up -d
docker compose -f docker-compose.yml -f docker-compose.release.yml ps
python3 ../../scripts/mcp/onboard.py doctor --directory "$PWD"
```

等待服务变为健康状态。未认证的 MCP 探测返回 `401` 属于预期行为；已认证的远程 MCP 任务仍依赖可用的身份服务与令牌。不要把密码或 Bearer 令牌放进 Skill 提示词、数据源 URL 或 shell 历史。

## 4. 添加合成数据源并完成首次查询

依次参阅[管理端与 MCP 身份准备](../mcp-deployment.md#5-prepare-management-and-mcp-access-tokens)、[注册样例数据源](../mcp-deployment.md#6-register-the-sample-source)和[首次查询](../mcp-deployment.md#7-connect-a-client-and-run-the-first-query)。样例记录均为合成数据。

使用 [Agent Skill 指南](../agent-skill.md) 配置已支持的客户端。Data Fabric 提供只读发现与查询，不是 ELT 数据搬运服务。SQL 转换可以在不执行查询的情况下转换已公布的方言，但它不保证任意厂商 SQL 语义可移植，也不授予数据源访问权限。

本预览优先评估已文档化的 MySQL 配置。接入其他类型前请查阅[数据源支持目录](../data-source-support.md)。浏览器接入候选功能、公开 WorkBuddy 自助开通、任意 MCP 客户端自动 OAuth，以及所有已注册类型/版本，均不由本指南承诺。

## 恢复与升级限制

请为本预览使用独立项目和新卷。v2.0.0 或更早预览版的原地升级并不是已验证承诺。对重要数据使用前，请自行用保留的密钥材料演练备份与恢复；配置备份不包含业务数据源和正在进行的查询游标。

请把准确的发布源码包、`.env`、TLS 私钥、凭据密钥环、镜像摘要及源码版本一并纳入变更记录。候选版本的已知限制（包括当前密钥环恢复边界和公开 OAuth/WorkBuddy 排除项）详见[候选记录](v2.1.0-preview.3-candidate-zh.md)。
