## What this preview is for

Evaluate one self-hosted, read-only gateway profile: register one approved MySQL source once, then reuse its policy from one REST application and one remote MCP application. The sample data is synthetic. This release makes no claim that an external team has validated the fit, that a real-model business task succeeds, or that an organization will pay for the product. The real-model task evaluation and paid-offer validation remain open under #456 and #459; this preview is not evidence of model quality, team retention, or willingness to pay.

The intended audience, operator roles, task, comparison method, and success rules remain hypotheses in the [first-adopter profile](../product/first-adopter-profile.md). This confirmation covers the version and technical Preview boundary; participant recruitment and external evaluation remain pending. Keep user-fit, model-quality, adoption, and willingness-to-pay claims explicitly unvalidated.

## Candidate highlights

- A tag-gated linux/amd64 GHCR image can be installed through the digest-pinned Compose overlay. The runtime image packages SQLGlot, project notices, and a deterministic bundle of license materials for modules imported by the server and replica-ingress binaries.
- The onboarding helper initializes secrets and local TLS files safely, creates a bounded management token, and diagnoses the local profile without resetting its data.
- The current-profile runbook verifies encrypted backups and prepares restore into a fresh Compose project.
- Query admission and active-stream limits, per-tenant limits, connection-pool bounds, and returned-result budgets make the tested profile more explicit. These limits are per process; they do not establish a cluster-wide quota or a host memory guarantee.
- MCP callers can select the documented pagination or streaming behavior. The public REST/MCP acceptance records candidate-matched continuation, mutation, denial, and lifecycle outcomes.
- A provider-neutral Agent Skill documents schema-aware, read-only queries and bounded result retrieval.
- UUID-typed values now reject malformed strings and byte slices.

See the [published changelog](../../CHANGELOG.md) for the complete change list.

## Resource and behavior limits

The measured first-profile defaults allow up to four active query or stream reservations per API or MCP process, with at most two for a validated tenant in that process. The default SQL pool permits up to ten open connections per source and process. A query has a 64 MiB returned-result budget.

These are admission and output limits. They do not cap source scan work, total process heap, CPU, or aggregate use across replicas. The returned-result budget is not a memory-envelope or production-capacity guarantee. See the [current operating limits](../roadmap.md#current-operating-limits) and [query observability guidance](../observability.md#current-query-and-cursor-capacity).

Continuation cursors are process-local. Restarting their owner loses in-flight continuation state. This profile does not provide shared cursor storage, replica failover, or a cluster-wide tenant budget. Persist the credential keyring and follow the backup/recovery runbook; recovery does not restore live query cursors.

The SQL surface remains a documented read-only subset. Cross-source joins, write access, universal SQL compatibility, masking, arbitrary column policy, and production readiness across every catalog connector are outside this preview.

## Upgrade and recovery

The latest stable release is v2.0.0. The existing [upgrade guide](../upgrading-v1.2.0.md) covers v1.2.0 to v2.0.0; it is not evidence of a tested v2.0.0-to-preview upgrade.

For this Preview, use a fresh, isolated Compose project and synthetic or explicitly approved data. Do not point an existing production metadata volume at the preview image. No in-place upgrade from v2.0.0 and no migration from Preview to a future Stable release are promised. Treat preview metadata as evaluation data and retain a verified backup before changing the candidate. The [backup and recovery runbook](../operations/mcp-profile-backup-recovery.md) is bound to a candidate source revision and restores into a fresh project.
