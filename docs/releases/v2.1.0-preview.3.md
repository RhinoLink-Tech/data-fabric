## Evaluated user path

The evaluated self-hosted path uses MySQL 8.4 metadata and synthetic MySQL sample data. It supports authorized REST management and remote MCP only when the operator provides a trusted HTTPS endpoint and an explicitly configured external OIDC issuer, audience, and scopes. The package includes read-only source discovery and queries, bounded pagination, and SQL dialect conversion that does not execute SQL.

Use the installation guide for the checksum-verified archive and the exact image reference. Do not replace the image digest with a floating tag.

## Boundaries retained from the candidate review

The public WorkBuddy service, account self-service, generic client automatic OAuth, actual marketplace lifecycle, external adoption, and real customer-data outcomes were not established by this release. Browser onboarding for MariaDB, openGauss, and TiDB remains default-off candidate functionality with source-specific conditions. Consult the historical candidate record before evaluating those paths.
