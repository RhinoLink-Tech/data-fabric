# WorkBuddy 接入 Data Fabric

在 WorkBuddy 中选择要使用的 Data Fabric 连接器：在线体验连接器连接其固定服务；自部署连接器连接用户或团队自己的服务。自部署连接表单填写服务域名、端口和 /mcp 路径（不要填写 https:// 前缀）以及该服务认可的 MCP 访问令牌；这个令牌不会由自部署连接器自动刷新，到期需从身份提供方重新获取并更新表单。可用能力取决于服务实际启用的工具、数据源、身份和权限；安装 Skill 不会自动部署服务或创建数据源。数据库必须能从服务访问。数据库密码和访问令牌不要发送到聊天中。

通过 list_source_types 了解注册的数据库和文件格式；注册、实例类型策略和向导类型策略均不代表数据源已配置、已获授权或所有版本均已验证。先列出当前用户有权访问的数据源，再检查表结构，执行授权的只读查询。订单查询示例使用合成业务数据，不代表真实客户数据。

具备管理权限时，可按已启用的工具重命名、启用、停用或测试已有数据源。删除前明确确认数据源名称与 ID。启用安全向导且对应工具可用时，可在经过身份认证的浏览器中新增允许的 PostgreSQL 或 MySQL 数据源；更新连接时检查 begin_data_source_update 和 get_data_source_update_status 是否可用。凭据只在浏览器输入；回到对话后检查工具返回的实际状态。权限、类型、允许的网络地址和 TLS 信任要求以服务配置为准。

连接失败时，检查网络、证书、身份和授权；令牌到期无法刷新时，按客户端提示重新授权。缺少工具或权限时，请管理员检查服务配置，不要绕过安全限制。
