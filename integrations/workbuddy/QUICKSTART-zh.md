# 在 WorkBuddy 中开始使用 Data Fabric

这份指南面向已经部署 Data Fabric 的团队。管理员先准备一次服务和数据源；每位使用者再将 WorkBuddy 连接到该服务，然后直接提问。

## 管理员准备一次

1. 按[中文部署指南](../../docs/mcp-deployment-zh.md)启动 Data Fabric。记下 WorkBuddy 可访问的 HTTPS MCP 地址（以 `/mcp` 结尾），并确认客户端信任证书。发布的 Preview 为单机体验配置，具体前提和范围见部署指南。
2. 在管理 API 的 `/ui/` 页面添加并测试数据源，启用数据源，并按实际需要配置使用者的身份、租户和读取权限。管理 API 的访问地址以部署配置为准，不能假设与 MCP 端口相同。使用合成数据试用时，参考[示例订单验收](../../docs/agent-skill-zh.md#用合成订单验收)。
3. 从配置的身份提供方为使用者获取符合服务 issuer、audience 和 scope 要求的 MCP 访问令牌。管理 API 的 JWT 与 MCP 访问令牌不能互换。

## 使用者连接并提问

在市场连接器正式发布之前，先按[客户端接入指南](../../docs/agent-skill-zh.md#workbuddy)手动导入 Skill、创建自定义连接器，并填写管理员提供的 MCP 地址和访问令牌。不要把令牌或数据库密码写进聊天消息。过期后从身份提供方重新获取令牌并更新连接器。

连接并启用后，在 WorkBuddy 会话中输入：

> 使用 Data Fabric，列出我可以访问的数据源，找到订单表并查看字段。然后查询最近的订单，按需获取后续结果。

当已连接服务提供类型发现工具时，也可以问：

> Data Fabric 当前支持哪些数据库、对象存储和文件格式？请按分类说明，并标明已验证的版本。

类型发现列出服务当前构建中注册的连接器，不代表已配置或所有版本均已验证。受限候选服务分别返回实例类型策略和向导类型策略标记，但不保证连接、授权或版本兼容。旧版服务可能没有该工具；此时请查看版本对应的支持目录。

先检查连接器是否可用；如果看不到数据源，请管理员核对来源是否启用、用户身份和授权。如果连接失败，核对 MCP 地址、网络、证书信任以及令牌有效期和范围。失败时不要绕过证书检查。

## 上架后的目标体验

管理员仍需准备 Data Fabric 服务、身份和数据源。用户在 WorkBuddy 市场安装连接器，在连接表单中填写服务域名、端口和路径（不带 `https://`）以及 MCP 访问令牌，再开始提问。当前连接器包尚未上架；市场导入及本机连接、查询的完整流程仍需实测。

更多能力和 API 用法见[项目首页](../../README_zh.md)及[API 使用指南](../../docs/api_usage.md)。

## 连接自己的数据源

本连接器需要可由 WorkBuddy 访问的 Data Fabric MCP 服务。用户可以在自己网络中部署 Data Fabric 镜像并配置数据库，或连接其有权限使用的已有服务。MCP 与数据库之间要具备网络连通性；WorkBuddy 中的 `localhost` 指连接器实际运行环境，不一定是用户电脑。按部署环境配置 HTTPS、身份认证和网络访问，避免将数据库端口直接开放。演示地址只使用合成数据，不是用户自己的数据源。

当前已发布的 v2.1.0-preview.1 镜像支持已配置数据源的发现与只读查询；它不包含后来合入主线的类型发现和数据源管理工具。仅在部署了包含这些工具的较新服务、且客户端实际发现工具时，才能使用以下功能：

- **了解支持范围**：询问“当前服务支持哪些数据库和文件格式？”；进一步询问指定类型时，助手会读取该类型的验证情况和限制。
- **管理已有数据源**：在具有 data-fabric.sources.manage 和所需所有权或管理员权限时，可要求重命名、启用或停用；更改前核对数据源和目标状态。
- **测试连接**：可测试已配置的 MySQL 或 PostgreSQL 数据源。普通部署仅支持非 TLS；启用受限向导的候选服务可测试验证证书的 TLS 连接。
- **删除**：明确确认数据源名称和 ID 后才执行；该操作永久删除，服务端还要求对应租户和所有权。

**安全新增（源码候选）**：尚未发布镜像且尚未完成 WorkBuddy 客户端端到端验收。管理员部署并启用候选后，只有实际发现 `begin_data_source_onboarding` 和 `get_data_source_onboarding_status`，才可请助手启动向导。打开返回的链接，用与 MCP 相同的 issuer、用户和租户登录，在浏览器安全填写连接信息、测试并保存，回到会话告知助手，再由助手读取真实状态。链接本身不授予权限。候选仅支持服务器允许的 IPv4 地址和端口上的 PostgreSQL/MySQL，支持验证服务端证书的 TLS；还需要 OIDC、管理 scope 和服务端身份授权。暂不支持安全向导添加其他类型或修改已有连接凭据。已发布的 v2.1.0-preview.1 不包含安全新增工具。

如工具缺失、权限或连接失败，请管理员核对版本、授权和网络策略，或通过管理 UI 安全配置。切勿在聊天中发送密码或令牌。部署后应以实际服务和工具列表为准。
