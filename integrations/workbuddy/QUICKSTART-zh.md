# 在 WorkBuddy 中开始使用 Data Fabric

这份指南面向已经部署 Data Fabric 的团队。管理员先准备一次服务和数据源；每位使用者再将 WorkBuddy 连接到该服务，然后直接提问。

## 管理员准备一次

1. 按[中文部署指南](../../docs/mcp-deployment-zh.md)启动 Data Fabric。记下 WorkBuddy 可访问的 HTTPS MCP 地址（以 `/mcp` 结尾），并确认客户端信任证书。发布的 Preview 为单机体验配置，具体前提和范围见部署指南。
2. 在管理 API 的 `/ui/` 页面添加并测试数据源，启用数据源，并按实际需要配置使用者的身份、租户和读取权限。管理 API 的访问地址以部署配置为准，不能假设与 MCP 端口相同。使用合成数据试用时，参考[示例订单验收](../../docs/agent-skill-zh.md#用合成订单验收)。
3. 从配置的身份提供方为使用者获取符合服务 issuer、audience 和 scope 要求的 MCP 访问令牌。管理 API 的 JWT 与 MCP 访问令牌不能互换。

## 使用者连接并提问

在市场连接器正式发布之前，先按[客户端接入指南](../../docs/agent-skill-zh.md#workbuddy)手动导入 Skill、创建自定义连接器，并填写管理员提供的 MCP 地址和访问令牌。不要把令牌或数据库密码写进聊天消息。过期后从身份提供方重新获取令牌并更新连接器。

连接并启用后，在 WorkBuddy 会话中输入：

> 使用 Data Fabric，列出我可以访问的数据源，找到订单表并查看字段。然后查询最近的订单，按需获取后续结果。

先检查连接器是否可用；如果看不到数据源，请管理员核对来源是否启用、用户身份和授权。如果连接失败，核对 MCP 地址、网络、证书信任以及令牌有效期和范围。失败时不要绕过证书检查。

## 上架后的目标体验

管理员仍需准备 Data Fabric 服务、身份和数据源。用户在 WorkBuddy 市场安装连接器，在连接表单中填写服务域名、端口和路径（不带 `https://`）以及 MCP 访问令牌，再开始提问。当前连接器包尚未上架；市场导入及本机连接、查询的完整流程仍需实测。

更多能力和 API 用法见[项目首页](../../README_zh.md)及[API 使用指南](../../docs/api_usage.md)。
